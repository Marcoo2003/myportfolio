# Design Context

## Users
Recruiters at product companies, freelance clients, fellow developers. All arrive with different contexts — some want to skim fast, others want to dig in. Must work for all three without compromising on personality.

## Brand Personality
**Precise. Ambitious. Creative.**

The portfolio owner builds real things, understands the hard parts, and doesn't hide behind vague buzzwords. The interface should feel like someone who actually knows what they're doing — not someone who generated it.

## Aesthetic Direction
**Technical dark, genuinely distinctive.**

Dark-first with a warm amber/gold accent instead of the ubiquitous cyan/blue. This single swap instantly separates the portfolio from 90% of "dev portfolio" AI slop. Light mode uses warm cream tones with the same amber accent for cohesion.

**Anti-references:** Generic vibe-coded full-stack dev portfolio — dark background, glowing cyan, Geist font, cards with subtle borders, matrix text effects, boot sequences that overstay their welcome.

**Typography:** Replace Geist with IBM Plex Mono (display/accent) paired with a clean grotesque sans. Lean *into* the technical aesthetic but do it with restraint and drama — not with scanlines and CRT noise.

**Color system:**
- Dark: `#0d0c0b` (warm charcoal, not cold black) + amber accent `#f59e0b` / `#d97706`
- Light: `#faf8f4` (warm linen) + same amber accent
- Remove cold blue entirely

## Design Principles
1. **Restraint over effects** — one great typographic moment beats ten animated gimmicks
2. **Warm technical** — technical precision expressed through warm tones, not cold neon
3. **Scale creates drama** — extreme size jumps (4–6x) do more than any particle system
4. **Both modes, one personality** — light and dark feel like the same person, not two different sites
5. **No decoration without function** — every visual element earns its place
